Améliorer mon IA

Dis-lui comment s’améliorer

Elle change elle-même ses réglages, sans passer par Claude : sa personnalité, sa façon de répondre, ce qu’elle retient, les mots interdits ou autorisés, ses actions, son moteur d’images, les couleurs de l’app… Chaque changement s’annule d’un bouton.

Code : elle se programme elle-même

Demande-lui une nouvelle fonction ou un changement dans l’app : elle écrit le code, le teste, corrige ses erreurs et l’ajoute tout de suite. Chaque module s’active, se désactive ou se supprime ici. Les modules restent sur ce téléphone.

Modules installés

Si un module casse l’app, ouvre le lien avec ?sans-modules à la fin : l’app démarre sans eux et tu peux les retirer.

Pour les gros changements

Changer le code, ajouter une fonction ou entraîner de nouveaux modèles demande une IA de programmation : Claude Code, celle qui a créé ton IA. Elle travaille sur ton projet GitHub et met les changements en ligne.

Comment faire

  1. Copie la demande ci-dessous et complète-la avec ce que tu veux.
  2. Ouvre Claude Code et choisis ton projet Strike-.
  3. Colle ta demande et envoie. Les changements arrivent ici quelques minutes après.
